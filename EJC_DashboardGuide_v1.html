The Three Control Types — How Each One Works
Controls Reference
Search Bar
Type to filter live
Start typing and results update instantly. Searches across all text in each item — city, state, note, signal, tags, titles, body text, sources, and EJC signals.
governance
Try: "governance" → surfaces all governance-failure items across crisis cards and juxta. Try "2013" → pulls every item referencing the pre-pandemic recession.
Filter Pills
Click to narrow by category
Each pill filters to a specific tag or theme. Active pill is highlighted teal. "All" resets the filter. Pills and search work together — filter first, then search within results.
All Districts Governance ESSER Cliff Federal Risk
Crisis: 5 cause tags. Scorecard: 5 themes. Synthesis: 4 argument themes. Market: 6 data categories. Revenue: 4 tiers. Talking Points: 4 rooms.
Sort Controls
Click column headers or use dropdown
Market Data table and Revenue table: click any column header. Click again to reverse direction. An arrow appears on the active sort column. Crisis cards have a dropdown for deficit size or alphabetical.

04
Tips, Shortcuts, and Things to Know
Pro Notes
🔍
Search and filter stack
Search and filter pills work together in every section. Click a filter pill first to narrow the category, then search within those results. Clear either to reset that layer independently.
↕
Click column headers twice to reverse
First click: sort ascending. Second click: sort descending. A ↑ or ↓ arrow appears on the active column. Works in both the Market Data table and the Revenue Model table.
⟷
Synthesis search works across both columns
In the Synthesis section, the search bar queries both the budget crisis column and the achievement data column simultaneously. Both paired items show or hide together — the connection between datasets stays intact.
→
Every source link is live
Every crisis card has a "Read the story" link that opens the original article in a new tab. Every source in the market data table is labeled. The Scorecard section has four direct links to the full report, Harvard coverage, Stanford SEDA, and Stanford press release.
⬆
Nav bar anchors are sticky
The top navigation bar stays fixed as you scroll. Click any section name to jump directly. The active section highlights in teal as you scroll through. On mobile the nav links hide — scroll or use browser navigation.
📊
Bar charts animate on scroll
In the Market Data section, the bar charts animate their fill when they enter the viewport. If you want to trigger the animation again, scroll away and back. Red bars = crisis indicators. Teal bars = EJC opportunity indicators. Green bars = positive trends.
✕
Clear search: just delete the text
There is no separate reset button. Delete your search text and all results return. Click "All" in the filter pills to reset the category filter. Both together = full data view restored.
⊞
Result count always shows
Every section with controls shows a result count line just above the data — "Showing X of Y items." This tells you how many results match your current filter and search combination at all times.
05
Pushing to GitHub Pages — Three Steps
Deployment
Step 01
Create the repo
Go to github.com → New repository. Name it ejc-crisis-dashboard. Leave it public. Don't add a README.
Or add to the existing ej25-lab org. The repo name becomes part of the URL.
Step 02
Add the file
Click "creating a new file." Name it exactly index.html. Paste the full contents of EJC_CrisisDashboard_v2.html. Commit to main.
Select all in the file → Ctrl+A / Cmd+A → paste. The file is ~73KB. Commit message: "Add crisis intelligence dashboard v2"
Step 03
Enable Pages
Repo Settings → Pages → Source: "Deploy from a branch" → Branch: main → folder: / (root) → Save. Live in ~60 seconds at the URL GitHub shows you.
Live URL format: https://ej25-lab.github.io/ejc-crisis-dashboard/ — Share this link. Single file. No maintenance. No dependencies.
